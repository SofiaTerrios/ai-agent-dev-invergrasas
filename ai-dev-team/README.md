AI Dev Team (ejemplo)

> **Estado:** ejemplo del boilerplate, no se usa en Invergrasas. Ningún
> proceso del backend ni del frontend depende de esta carpeta, y no se
> instala en CI. Se conserva como referencia para automatizar tareas con
> agentes; puede borrarse sin afectar la aplicación.

This folder can contain automation agents such as:

- LangGraph agents
- GitHub automation scripts
- AI planning tools

Agents can read:

docs/
tasks/
NEXT_TASK.md

and implement features automatically.
