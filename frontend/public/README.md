Place your hero background image(s) here.

- Default filename used by the site: `hero-bg.jpg`
- To replace the slider image, put your JPG/PNG at `frontend/public/hero-bg.jpg`.
- You can add different images and update `HERO_SLIDES` in `frontend/src/app/page.tsx` to reference them per-slide (e.g., `/hero-1.jpg`, `/hero-2.jpg`).

Example:
1. Copy your image file into `frontend/public/hero-bg.jpg`
2. Restart the dev server if needed: `cd frontend && npm run dev`
