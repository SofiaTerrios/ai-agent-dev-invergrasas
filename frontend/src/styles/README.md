# Frontend style tokens

This frontend uses the color system already established in the project:

- Primary green: `#1A8A3A`
- Secondary green: `#0F6E2E`
- Gold accents: `#D4A017` and `#C8880A`
- Amber accents: `#C86010` and `#A84800`
- Body text: `#3A3A3A`
- Base background: `#FFFFFF`

Typography:

- Headings: `Playfair Display`
- Body/UI text: `DM Sans`

Notes:

- Reusable UI components are under `src/components/ui`.
- Auth forms are under `src/components/auth`.
- Auth pages are grouped in `src/app/(auth)`.
